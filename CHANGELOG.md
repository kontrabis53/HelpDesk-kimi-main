# Changelog

Все заметные изменения в проекте **MEDIN HelpDesk** будут документироваться в этом файле.

## [1.1.1] - 2026-04-23
### Fixed
- Исправлена критическая ошибка `Cannot read properties of undefined (reading 'map')` в модуле «База знаний» при открытии карточки инструкции.
- Устранен сбой `Cannot read properties of undefined (reading 'find')` в модуле «Чат» при инициализации списка бесед.
- Исправлена ошибка отображения количества комментариев в `TicketCard` (проблема с доступом к `_count.comments`).
- Исправлена ошибка `401 Unauthorized` при попытке загрузки пользователей до авторизации.
- Исправлена ошибка `500 Internal Server Error` при входе в систему из-за отсутствия подключения к БД.

### Changed
- Оптимизирована работа Socket.io: принудительное использование протокола `websocket` для стабильной работы в локальных сетях.
- Разделена логика: модуль «Управление» теперь работает только с реальными пользователями CRM, в то время как «Справочник» содержит полный список сотрудников организации.
- Обновлен скрипт `seed.ts` для корректного импорта всех исторических данных из mock-файлов в PostgreSQL.

### Added
- Создана страница «О программе» с историей версий и описанием технологического стека.
- Добавлены защитные проверки (optional chaining) во все ключевые компоненты интерфейса.

## [1.1.0] - 2026-04-20
### Added
- **Грандиозный переезд на БД**: Полный отказ от статических mock-файлов в пользу PostgreSQL.
- **Инфраструктура**: Добавлена поддержка Docker и Docker Compose для быстрого развертывания базы данных.
- **Backend API**: Реализован полноценный сервер на Fastify с поддержкой JWT-авторизации.
- **Real-time**: Интеграция Socket.io для мгновенного обмена сообщениями в чате.
- **Dashboard**: Добавлена панель управления сервером для мониторинга логов и состояния системы в реальном времени.

### Changed
- Миграция всех существующих модулей: Заявки, Справочник, База знаний, Инвентарь, Документы.
- Обновлена структура проекта: разделение на `client` и `server`.

## [1.0.0] - 2026-03-01
### Added
- Начальная версия системы HelpDesk.
- Базовый интерфейс пользователя и техника.
- Модули: Заявки, Справочник, Склад.
