# Changelog

Все заметные изменения в проекте **MEDIN HelpDesk** будут документироваться в этом файле.

## [1.2.7] - 2026-05-03
### Added
- Реорганизация модуля «Реестр»: вынос управления оборудованием в отдельный вид «ОБОРУДОВАНИЕ».
- Создана полноценная таблица оборудования с детальной информацией о расположении (здание, этаж, кабинет).
- Улучшен интерфейс добавления оборудования: выбор кабинета из списка зданий с автоматической привязкой к отделению.

### Fixed
- Реализовано удаление и редактирование оборудования через современные диалоговые окна Shadcn/UI.
- Исправлена ошибка отсутствия методов `deleteEquipment` и `updateEquipment` в `locationStore`.

## [1.2.6.1] - 2026-05-03
### Changed
- Реорганизация модуля «Инструкции»: вынос управления техническими инструкциями из Реестра в выделенный модуль.
- Внедрение системы RBAC (Role-Based Access Control) для инструкций: разделение прав доступа на создание, редактирование и удаление.
- UI/UX: замена стандартных браузерных окон `prompt` и `confirm` на стилизованные диалоги Shadcn/UI в административной панели.

## [1.2.6] - 2026-05-02
### Added
- Внедрен iOS-style редактор аватаров с поддержкой Memoji и монограмм.
- Система истории аватаров: автоматическое сохранение 3-х последних изображений.
- Глобальный компонент `UserAvatar` для унификации интерфейса во всех модулях.

### Fixed
- Исправлены ошибки сохранения профиля на стороне сервера.
- Увеличены лимиты передачи данных (body-limit) до 10МБ.

## [1.1.9] - 2026-04-27
### Fixed
- Исправлена критическая ошибка дублирования уведомлений о входе пользователей.
- Реализована фильтрация повторных событий статуса через useRef и Map в RootLayout.
- Исправлен сброс переключателя уведомлений в профиле пользователя.
- Обновлен скрипт инициализации данных (seed): теперь он корректно обновляет существующих пользователей без ошибок уникальности.

### Changed
- Оптимизирована инициализация сокетов: предотвращена повторная авторизация при обновлении компонентов.
- Синхронизирована серверная и клиентская версии системы.

## [1.1.1] - 2026-04-23
### Fixed
- Исправлена критическая ошибка `Cannot read properties of undefined (reading 'map')` в модуле «База знаний» при открытии карточки инструкции.
- Устранен сбой `Cannot read properties of undefined (reading 'find')` в модуле «Чат» при инициализации списка бесед.
- Исправлена ошибка отображения количества комментариев в `TicketCard` (проблема с доступом к `_count.comments`).
- Исправлена ошибка `401 Unauthorized` при попытке загрузки пользователей до авторизации.
- Исправлена ошибка `500 Internal Server Error` при входе в систему из-за отсутствия подключения к БД.

### Changed
- Оптимизирована работа Socket.io: принудительное использование протокола `websocket` для стабильной работы в локальных сетях.
- Разделена логика: модуль «Управление» теперь работает только с реальными пользователями CRM, в то время как «Справочник» содержит полный список сотрудников организации.
- Обновлен скрипт `seed.ts` для корректного импорта всех исторических данных из mock-файлов в PostgreSQL.

### Added
- Создана страница «О программе» с историей версий и описанием технологического стека.
- Добавлены защитные проверки (optional chaining) во все ключевые компоненты интерфейса.

## [1.1.0] - 2026-04-20
### Added
- **Грандиозный переезд на БД**: Полный отказ от статических mock-файлов в пользу PostgreSQL.
- **Инфраструктура**: Добавлена поддержка Docker и Docker Compose для быстрого развертывания базы данных.
- **Backend API**: Реализован полноценный сервер на Fastify с поддержкой JWT-авторизации.
- **Real-time**: Интеграция Socket.io для мгновенного обмена сообщениями в чате.
- **Dashboard**: Добавлена панель управления сервером для мониторинга логов и состояния системы в реальном времени.

### Changed
- Миграция всех существующих модулей: Заявки, Справочник, База знаний, Инвентарь, Документы.
- Обновлена структура проекта: разделение на `client` и `server`.

## [1.0.0] - 2026-03-01
### Added
- Начальная версия системы HelpDesk.
- Базовый интерфейс пользователя и техника.
- Модули: Заявки, Справочник, Склад.
