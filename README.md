# HelpDesk CRM - Медицинская Система Поддержки (v1.2.7)

Современная экосистема управления заявками, ресурсами и коммуникациями, специально адаптированная для нужд медицинских организаций. Проект объединяет мощный Backend на Fastify, гибкий Frontend на React 19 и мобильную интеграцию через Capacitor.

## 🚀 Текущее состояние (v1.2.7)

На данный момент система находится в фазе активного расширения функционала. Основные достижения текущей версии:
- **Автономный сервер**: Полный переход на PostgreSQL с использованием Prisma ORM.
- **Real-time**: Поддержка мгновенных уведомлений и чата через Socket.io.
- **Интеллектуальный Профиль**: Продвинутая система управления аватарами (Memoji, история фото, монограммы).
- **Безопасность**: Ролевая модель доступа (RBAC) с детальной настройкой прав для каждого модуля.

## 🛠 Технологический стек

### Frontend
- **Ядро**: React 19, TypeScript, Vite
- **UI**: Tailwind CSS, Shadcn UI (Radix Primitives)
- **State Management**: Zustand (с персистентностью)
- **Анимации**: Framer Motion
- **Работа с датами**: date-fns

### Backend
- **Сервер**: Fastify (высокая производительность)
- **База данных**: PostgreSQL + Prisma
- **Real-time**: Socket.io
- **Валидация**: Zod
- **Безопасность**: JWT, BcryptJS, Helmet, Rate Limit

### Mobile & DevOps
- **Mobile**: Capacitor (Android поддержка)
- **Контейнеризация**: Docker, Docker Compose

## 📁 Основные модули

- **🎫 Заявки (Tickets)**: Полный цикл обработки технических и хозяйственных запросов.
- **📄 Документы (Documents)**: Календарное планирование, учет актов и медицинских документов в стиле iOS.
- **📦 Склад (Inventory)**: Учет IT-активов и медоборудования с отслеживанием местоположения.
- **📚 База знаний (Knowledge)**: Инструкции, руководства и регламенты для персонала.
- **💬 Чат (Chat)**: Внутренний мессенджер для оперативного взаимодействия.
- **👥 Управление (Admin)**: Контроль пользователей, прав доступа и системных логов.
